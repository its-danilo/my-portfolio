# my-portfolio

My personal portfolio: projects, skills and contact. Live at https://its-danilo.vercel.app

Built with Next.js, TypeScript, Tailwind CSS and Framer Motion. Projects and personal info live in `data/portfolio.ts`.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```

The kinetree demo at `/kinetree-demo` is a static Flutter web build in `public/kinetree-demo`. Refresh it with `scripts/update-kinetree-demo.sh` (needs podman, reads `../kinetree`).
